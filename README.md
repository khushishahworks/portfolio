# portfolio
Khushi Shah's portfolio: a one-page, butter-yellow site for small-business clients.

## Run it

Open `index.html` in a browser. No build step needed.

- `index.html`: page markup
- `styles.css`: colours, fonts and all animations
- `script.js`: rotating headline word (desktop) and typed word (mobile)

Scroll effects use CSS scroll-driven animations. Browsers without support (Firefox, last checked) show a static version with everything visible.
